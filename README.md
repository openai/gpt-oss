# BoolieLOT

BoolieLOT 是一個以古代學者與工程家的視角探索歷史思想和程式設計的實驗專案。它嘗試用典雅的繁體中文討論 1899 年以前的學問，並運用現代程式技術實作古典概念、模擬機械和製作遊戲。

## 專案現況

- 古典札記以文獻出處和知識年代記錄，涵蓋《天工開物》、達文西筆記與布爾邏輯等；後世版本的出版日期不等同於原文的年代。
- 聊天介面支援對話及程式碼展示；使用時須另行啟動並連接模型後端。
- 訓練流程可依已審核札記建立習卷和考卷，並以 LoRA 試驗古典表達。現有資料量很少，仍需擴充和驗證。
- Colab 曾完成一次 10 步試訓並產生附加權重；權重未包含在此儲存庫中，必須搭配相容的底座使用。

此專案使用現代預訓練底座。微調與年代限制不能保證移除底座中 1899 年之後的知識；程式設計能力亦需要現代技術。模型的歷史可靠性、文言風格與程式能力仍須獨立測試。
